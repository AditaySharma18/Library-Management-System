# Library Management System
 
## 📚 Overview

The **Library Management System** is a comprehensive software solution designed to streamline library operations such as book inventory, user management, and lending processes. Built with Java, the system is scalable and user-friendly, making it ideal for libraries of any size.

---

## ✨ Features

- 📖 **Book Management:** Add, update, and remove books from the catalog.
- 👤 **User Management:** Register, update, and track library members.
- 🔄 **Lending System:** Manage book issues, returns, due dates, and overdue penalties.
- 🔍 **Search:** Quickly locate books and users with advanced filters.
- 📊 **Reporting:** Generate reports on inventory, issued books, and overdue items.

## 🚀 Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/AditayCodes/Library-Management-System.git
   ```

2. **Navigate to the project directory:**
   ```sh
   cd Library-Management-System
   ```

3. **Compile and run the application:**
   ```sh
   javac Main.java
   java Main
   ```
